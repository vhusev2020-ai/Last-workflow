## Status meanings
- **IDEA** — recorded, not yet evaluated.
- **EXPLORING** — research and discovery underway.
- **EXPERIMENT** — small test in progress.
- **IN DEVELOPMENT** — approved build work underway.
- **VALIDATION** — testing real-world usefulness and reliability.
- **ACTIVE** — in regular use or operation.
- **PAUSED** — temporarily inactive; reason recorded.
- **ARCHIVED** — retained for history and learning.
- **NEEDS REVIEW** — existing work whose condition or next step is not yet confirmed.

## Project record template
For each new project, capture:
- Name
- One-sentence purpose
- Problem or opportunity
- Domain(s)
- Founder / responsible person
- Current status
- Current stage
- Next action
- Success measure
- Resource or budget limit
- Risks and dependencies
- Repository / document links
- Last reviewed date

Do not infer project health from the existence of a repository. Inspect and verify first.
